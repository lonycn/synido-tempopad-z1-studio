# v2.1 审查与交付记录

## 规划与分工

两个只读子任务独立核查官方RGB输出、实体索引、黑屏和模式控制；主线实现。实现后一次独立审查发现四项问题，修复后再次独立复核。

## 已修复问题

1. 末尾黑屏可能被节流永久丢弃：rendered/sent/pending分离，pending黑屏保持到成功或有限失败。
2. 多个设备可能串灯：唯一实体输出，真实输入必须与输出同一MIDIDevice；多个匹配输出fail closed。
3. clear/模式切换可能绕过限频并重复发送：统一drain，严格间隔100ms，成功帧去重，授权变化不重置限频。
4. 旧自动EASY回调覆盖更新的手动选择：ModeIntent手动代次预留，待应用手动命令优先，UI发布检查代次和模式。

## 已执行检查

- 源码优化编译、正式应用构建、严格签名验证。
- 模型、扩散、RGB编码、限频、尾部黑屏、失败重试、设备选择、代次和离线音频测试。
