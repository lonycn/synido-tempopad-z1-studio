Z1 Studio v2.1 使用说明

界面顺序：EASY → DRUM → KEY。

打开桌面「Z1 演奏助手.app」。所有声音都在助手里，不需要官方软件。
主目录：你克隆本仓库的位置（下文路径均相对该目录）。

DRUM：界面选 DRUM，硬件按 DRUM。
四个4×4分区按实物排列，64个位置有声，扩展区会复用音色。

KEY：界面选 KEY，硬件按 KEY。
白键／黑键和根音按真实布局显示。暗格是原厂停用键。
某些边界 C 在两处重复，输入音高相同，所以屏幕会同时标亮。
硬件移调／八度变化后，在右侧“硬件显示偏移”选择相应半音数。

EASY：界面选 EASY，硬件按 EASY，使用内置64格入门声音。
首次敲实体EASY垫时，助手可自动识别并切到EASY，再开始播放声音和扩散灯光。
这不是“刚按EASY模式键就识别”；DRUM/KEY没有可靠模式报告，仍需手动同步。
若没有输入，保持助手 EASY，硬件改按 DRUM 即可用标准 MIDI 路径演奏。
也兼容 USER（CH3），但 USER 原厂输入固定满力度。
1–16号格（最下面两排）为鼓／打击乐，17–64号为五声音阶拨弦音。
松开不会截断样本，支持最多32声部重叠，超出时替换最早的声音。
收到真实EASY输入确认后，实体灯光和屏幕从敲击处彩色扩散，约1.15秒淡出。
使用已核实的官方RGB消息，最多12个波纹重叠。只向唯一、配对的实体Z-1输出。
右侧显示“EASY已识别/等待确认”或输出错误。多台Z-1连接时关闭RGB输出。
停止所有声音会结束灯效并尝试清灯。原厂模式键没有已确认报告，按键后尚未敲新垫时，旧动画可能短暂继续。
尚未找到软件切换硬件模式的安全命令；软件选DRUM/KEY后，请按实体同名键。

鼠标：按住、拖过屏幕格即可试听；松开释放钢琴音符。默认力度100。
底部主音量调节声音；右侧显示连接状态、音源状态和最近一次敲击力度。
“停止所有声音”或 ⌘.：立即停止所有音符、延音和采样。

无声排查：
1. 确认 Mac 没有静音、当前输出设备正确；声音不从 Z-1 本体发出。
2. 看侧栏 AUDIO ENGINE 是否就绪，点“试听当前音源”区分音频与MIDI问题。
3. 看 MIDI DEVICE 是否连接，实际敲击后次数是否增加。
4. DRUM/KEY 需要硬件与助手同步选择，硬件模式键不会自动切电脑音源。
5. EASY 无输入先用硬件 DRUM 备用；不要为此升级固件或恢复出厂。
6. 不要同时开多个宿主；助手只会请求正常退出，不会强杀未保存工程。

仍需官方实体扩散灯光时：退出助手，手动打开 Synido 官方软件，进入Easy并载入：
projects/easy/Z1_EASY_Lights.eas
原始工程未改动，GarageBand备用工程也仍保留在 projects/garageband/。
